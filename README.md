# Restaurant OS - Nou Espantall

Sistema operativo para restaurantes con integración de voz ElevenLabs.

## Características
- Carta digital interactiva
- Control por voz con ElevenLabs (MCP)
- Gestión de pedidos y carrito comanda voz

## Despliegue
Este proyecto está desplegado en Vercel y conectado a ElevenLabs.
